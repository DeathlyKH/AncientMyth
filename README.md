# Ancient Myth

> A Vanilla+ exploration and combat mod centered on ancient flora, forgotten knowledge, and lost worlds.

**Ancient Myth** is a Minecraft Fabric mod about rediscovering remnants of an ancient ecosystem and the rules of the world that were lost with it.

Ancient plants are more than decorative crops. Their properties can influence brewing, equipment, exploration, combat, and interactions with the world itself. As progression expands, players will uncover forgotten structures, inscriptions, unusual creatures, powerful enemies, and secrets connected to the ancient cities and worlds beyond them.

The project is currently in **early development**.

## Design Direction

Ancient Myth is designed as an exploration-driven **Vanilla+** expansion rather than a technology or automation mod.

Its core principles include:

- Ancient plants interact with existing Minecraft systems instead of acting as machines.
- Exploration and discovery are the primary sources of progression.
- Inscriptions grant tools and equipment unusual world properties rather than simply increasing numerical stats.
- Powerful mechanics should create new possibilities instead of functioning as arbitrary progression keys.
- Boss encounters should interact with general game mechanics and allow multiple viable strategies.
- Industrial automation is never required for normal progression.
- New dimensions and systems should expand the Overworld experience rather than replace it.

The goal is to make Ancient Myth feel like a collection of forgotten rules that could have always existed beneath Minecraft's surface.

## Planned Content

Ancient Myth is expected to explore systems such as:

- Ancient plants and lost ecosystems
- Sniffer-related exploration
- Brewing enhancements
- Inscriptions and inscription combinations
- Ancient structures and ruins
- New villagers and ecological settlements
- Unique creatures and guardians
- Boss encounters
- Expanded interactions with normally unobtainable or unusual blocks
- Ancient City-related progression
- A lost ancient dimension

These systems are still being designed and implemented. Their final form may change during development.

## Development

Ancient Myth currently targets:

- **Minecraft:** 26.3
- **Mod Loader:** Fabric
- **Java:** 25
- **Language:** Java

The project uses split client/common source sets and Fabric Data Generation.

### Building

Clone the repository and run:

```bash
./gradlew build
```

On Windows:

```powershell
.\gradlew.bat build
```

Build artifacts will be generated under:

```text
build/libs/
```

### Running the Development Client

On Windows:

```powershell
.\gradlew.bat runClient
```

A Java 25 JDK is required.
